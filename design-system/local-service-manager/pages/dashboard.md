# 本地服务控制台页面覆盖

本页按已生成设计系统的深蓝、专业蓝与浅灰色实施。原始检索把产品误归类为 Local Events & Discovery，营销页结构、Hero/CTA 转化、活泼块状风格不适用于日常管理台，本覆盖明确替代这些建议。

- 产品布局：左侧紧凑品牌与导航；右侧页标题、状态概览、服务列表。扫描为显著操作，添加为次操作。
- 白色卡片与淡灰背景；蓝色主操作；绿/橙/红状态均配文字。
- 系统字体 Segoe UI / Microsoft YaHei，无外部字体、CDN、照片或插画依赖。
- Iconify Material Design Icons 的内联 SVG；仅辅助文本，不独立承担语义。
- 列表明确显示名称、版本、目录、状态；详情与编辑使用原生 dialog，支持 Escape 关闭和焦点恢复。
- 375/768/1024/1440px 响应式，窄屏侧栏改顶栏、卡片纵向、操作换行；长路径换行，无页面横向溢出。
- 动态只用于连接/启动/扫描反馈；无装饰动画，尊重 prefers-reduced-motion。
- 可聚焦控件至少 44px；所有字段有 label，错误就近显示。断线保留旧状态但冻结修改。
- 每 3 秒更新状态，不替换正在编辑的表单；日志仅在详情打开时拉取，可暂停滚动及复制。
