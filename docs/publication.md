# 发布快照说明

本仓库发布的是本地服务台 1.1.0 的源码快照，包含桌面无窗口启动入口、扫描黑名单和测试。保留目标仓库原有 README 初始化提交的历史。

未包含开发机上的服务登记、58 项黑名单的具体目录、进程记录、日志、快捷方式、测试产物、缓存或环境/密钥文件。开发机的用户名路径和项目根目录已在发布副本中替换为通用示例，本地工作副本与运行配置保持原样。

上传前对源码和发布副本运行静态审计，并比对已知本机接入值。审计器在 `tests/test_manager.py` 的脱敏测试中命中两个规则：刻意构造的 `sk-fake…` 字符串，以及值为 `FAKE_TOKEN_456` 的 token 示例；均已核实为公开的合成测试数据，不是接入凭据。发布副本未发现真实凭据或用户目录路径。

测试只使用隔离的本地进程与无业务副作用的接口；不会为了验证发布而调用字幕转写、语音克隆或数字人生成。

发布副本独立运行 `python -m unittest discover -s tests -v`：21 项通过，耗时 40.378 秒；Python 编译、JavaScript 语法与暂存差异检查均通过。
