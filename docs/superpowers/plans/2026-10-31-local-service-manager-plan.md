# 本地服务管理台实施计划

日期：2026-10-31；依据需求 v0.2。未安装 writing-plans 技能，本计划直接编写。

## 技术与边界

- Python 3.11+ 标准库 ThreadingHTTPServer + psutil 7.x；当前机器 python.exe 已有 psutil 7.2.2。原生 HTML/CSS/JS，不安装 Node 或联网依赖；固定入口 http://127.0.0.1:17861。
- 静态发现与进程控制分模块。扫描实际枚举 Windows 固定磁盘，使用 os.scandir 遍历，不跟随 reparse point，排除系统/依赖/缓存/本项目运行测试目录。限制单文件 256 KB，不读取 .env、密钥、素材，不执行候选代码。取消与访问失败保留覆盖摘要。
- 稳定身份为规范化安装目录+入口类型的 SHA256 截断值；版本从 package.json/pyproject.toml/已知 __version__ 静态提取，目录名仅标推测。增量合并保留手工配置，不因名称覆盖其他安装。
- 配置与实例记录分离，以原子替换 JSON 持久化；运行 PID 必须同时核对创建时间、程序路径、工作目录和命令摘要。监听与健康检查通过后才报告运行。外部进程只读，不能通过端口直接接管/杀进程。
- Windows 每次启动使用独立隐藏控制台；通过独立辅助进程附加该控制台发送 Ctrl+Break 正常退出。正常停止超时保留进程，要求用户显式选择强制。不通过任务名、端口或未验证旧 PID 批量结束。
- 管理台只监听 127.0.0.1；所有 API 要求精确 Host，变更请求精确 Origin + 内存会话 token，自定义请求头与 JSON 类型；同源页面获取 token，不允许跨站读取。API 不提供任意文件读取，只读取服务自身管理台日志。
- 退出后台保留业务进程。重复入口通过固定端口、实例标识与磁盘状态/进程核对复用；后台启动重新验证运行身份。
- 实施中补充独立轻量 worker 持续收集脱敏日志，后台退出不会关闭业务输出管道。停止脚本进程独立记录，超时仅回收本次控制辅助进程；恢复后存在未结束控制进程时阻止重启。

## 两个工具接入

VideoToNo 直接执行项目 .venv Python 的 uvicorn backend.main:app，明确回环地址/配置端口，使用 /api/health；不调用原 start.ps1，避免该脚本的旧 PID 复用与失败自动强杀影响外部实例。不读取 .env；用户可在配置更改端口。AutoVid 使用全局 Python，项目 __init__.py 自行加载 .pylibs；执行 -u -m autovid web，监听实际归属端口与 stdout URL，GET / 探活。不触发转写、生成或云端任务。

## 实施顺序

1. 静态扫描、版本识别、配置存储与预置适配器。
2. 身份安全、隐藏进程、捕获脱敏轮转日志、正常/强制停止、恢复、健康检查。
3. 本机 API 与固定启动/退出入口。
4. UI 子任务：使用已运行 UI UX Pro Max design-system 中专业蓝色/清晰层级，覆盖其营销页结构建议，形成适合本地控制台的卡片与侧栏；中文、键盘、响应式、断线与扫描反馈。
5. 扫描/无执行/版本去重/合并/API保护/并发生命周期/真实隔离HTTP服务测试。
6. 向主代理报告已有实例后，正常用户上下文验证两个真实工具及 AutoVid 换端口；只停止本次创建实例。
7. README、验收记录、限制与后续维护说明。

## 验证重点

扫描必须发现硬编码两项以外的 Node/Python/脚本示例。监听元数据不可用时显示权限问题，不能以 HTTP 200 猜测归属。Windows 控制台正常退出必须实测，失败则保持可强制停止状态并如实记录。测试与运行产物仅写本项目。用户后续已授权使用 Git 做本地版本控制；GitHub 上传等待用户提供目标仓库，不写知识库或部署公网服务。

实施结果：专属控制台正常停止已在隔离HTTP、VideoToNo、AutoVid上实测通过；后台真实进程退出/重开恢复通过。补充非敏感env、显式动态URL发现及停止脚本高级配置。一键扫描默认固定磁盘，最近范围保存于浏览器；纯Python清单无服务证据不登记，自身管理台与构建工具链默认排除。详细结果见 ../../verification.md。
