# Local-Service-Console

本地服务控制台：一键扫描本机工具，按版本和目录区分，集中启动、停止、重启并查看日志。

适用于 Windows 本机使用，使用 Python 标准库、psutil 和原生 HTML/CSS/JavaScript。管理台仅监听 `127.0.0.1`，不需要管理员权限；运行时不依赖 Node。

## 安装与首次打开

安装 Python 3.11 或更新版本，并确保 `python`、`pythonw.exe` 在 PATH 中。首次安装在 PowerShell 中执行：

```powershell
git clone https://github.com/2528078765/Local-Service-Console.git
cd Local-Service-Console
python -m pip install -r requirements.txt
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\create-desktop-shortcut.ps1
```

之后双击桌面的 **本地服务台**，自动启动后台并打开 **http://127.0.0.1:17861**，无需手动输入命令，不显示命令窗口。也可以双击项目中的 **启动管理台.cmd**。重复打开会核实并复用后台；端口被其他程序占用时会提示，不会打开占用者的页面。

桌面入口通过 `pythonw.exe` 运行 `desktop_launcher.pyw`；出错时显示中文提示并记录本项目运行日志。项目移动后可重新执行快捷方式创建脚本。快捷方式包含本机路径，不随仓库分发；不会注册浏览器协议或设置开机启动。

管理台不会自动安装业务项目的依赖，也不会替它们下载模型、配置密钥或提交生成任务。

关闭网页：后台及业务服务继续运行。双击 **退出管理后台.cmd** 或使用网页的“退出后台”：业务服务继续运行，重开管理台重新核实身份。停止某个业务服务请用该服务的“停止”。

## 自动扫描

点击顶部 **自动扫描** 就开始扫描。首次默认枚举本机可访问的固定磁盘；以后沿用在“扫描设置”中保存的范围。可在设置中指定目录并增加排除项。设置保存在当前浏览器的本地存储，换浏览器首次使用默认磁盘。

扫描真实遍历磁盘，静态读取有限大小的服务声明和明确入口，识别：

- Node `package.json` 的 start/dev/serve/web 脚本，优先明确的 start；有多个无法确定的入口则待配置。
- Python 网页框架的常规入口及项目版本声明；纯库或只有 pyproject 元数据的项目不会登记。
- start/serve/launch/启动服务类 CMD、BAT、PowerShell 脚本。
- AutoVid 和 VideoToNo 的源码入口适配器，实际位置可以与首批预设目录不同。
- 已运行 Python/Node 等进程的目录与监听元数据线索；线索始终只读，不会因此自动接管。

扫描不执行候选脚本、不导入候选模块、不读取 `.env`、密钥文件或业务素材。单个声明文件上限 256 KB。默认排除 Windows、回收站、系统卷、依赖、虚拟环境、工具链/构建缓存，以及管理台自身；不跟随目录联接和符号链接。摘要包含实际目录计数、排除、无权读取、取消等情况，不声称覆盖被排除区域或识别所有可执行程序。

同名项目通过真实目录确定独立身份，版本从清单/源码中的明确声明取得，未知就显示未知。不同版本、同版本不同目录均保留；同一安装升级会更新版本。重复扫描不会增加重复登记，也不会覆盖手工改过的启动配置。失效目录会提示，可自行修复或移除登记；移除不删除项目文件。

## 扫描黑名单

不想再看到的工具可以在未运行时点击「加入黑名单」。这会移除管理台登记，并按具体安装目录持久化忽略后续扫描；相同名称但安装在其他目录的版本不受影响。同一目录内升级版本仍会保持屏蔽。

左侧「扫描黑名单」可查看名称、版本和目录，也可逐项解除。解除不会启动程序，下次扫描时才重新发现。正在运行或启停操作中的服务不能加入黑名单。规则保存在 `runtime/blacklist.json`，不会提交到 Git。扫描摘要会显示黑名单忽略数量。

普通「移除」仍只移除登记；如果不希望下次扫描重新出现，请使用「加入黑名单」。

## 首批两个工具

| 工具 | 已验证版本 | 运行入口 | 默认网页 |
| --- | --- | --- | --- |
| 视频转字幕 VideoToNo | 1.4.6，来源 backend/main.py 的 FastAPI.version | 项目 `.venv\Scripts\python.exe -u -m uvicorn backend.main:app --host 127.0.0.1 --port 8000` | http://127.0.0.1:8000 |
| AutoVid | 0.1.0，来源 autovid/__init__.py 的 __version__ | 所配置的 Python `-u -m autovid web --host 127.0.0.1 --port 8899` | http://127.0.0.1:8899/，占用时跟随真实新端口 |

预设目录是管理台相邻的 `video-to-note-1.4.6` 与 `shortvideo-agent`。可用配置界面修改安装位置、解释器或端口。

字幕工具采用独立托管命令，**没有调用原 start.ps1 / stop.ps1**，避免原脚本用旧 PID 复用实例、启动失败自动强杀的行为。管理台不读取 `.env` 的 HOST/PORT/RELOAD，默认显式绑定 127.0.0.1:8000、不开热重载；若原来改过端口，请同步修改管理台命令与地址。项目自己正常加载业务配置的行为由项目决定。管理台捕获的日志在本项目 runtime 中，不覆盖项目原 `.runtime` 日志。

AutoVid 项目自身加载 `.pylibs`，不需要管理台读取业务 secrets。两个工具实测只访问首页与健康检查，没有提交字幕转写、数字人或其他云端任务。

## 添加与配置

填写名称、项目目录、程序路径和参数。命令区域 **每行一个参数**，中文、空格路径不需要手工加引号。例如：

```text
python.exe
-u
-m
http.server
8085
--bind
127.0.0.1
```

访问地址填 `http://127.0.0.1:8085/`。保存只登记，不执行。若程序动态选择端口，可开启高级选项“动态地址发现”；只有本次实例的真实监听归属和 HTTP 健康检查都通过后，才会报告运行并打开网页。多个不明确监听需要配置明确地址。

高级设置提供：HTTP/进程检查、健康路径、1–600 秒启动期限、非敏感环境变量 JSON、可选停止命令。环境变量继承当前用户环境，不保存名字包含 key/token/secret/password 等的变量；业务凭据继续由原项目自己的配置提供。停止命令也是逐行参数，`{pid}` 会替换为核实到的业务子进程编号，必须使用只停止该实例的脚本；管理台不会自动选择扫描得到的停止脚本。正常停止脚本超时会清理本次控制辅助进程，防止延迟影响后续实例。

默认正常停止通过本实例独立隐藏控制台发送 Ctrl+Break。15 秒内未退出会保留业务进程，明确提示；需要中断任务时再选择“强制停止”。外部启动的实例只读，不提供停止/重启。停止本地进程不代表取消已提交的云端任务。

运行中锁定目录、命令、地址、检查及停止配置，可修改名称、描述和启用状态。停用不自动停止现有进程。移除运行中托管服务前必须先停止。

## 数据与本机接口

- `runtime/services.json`：服务配置；`runtime/instances.json`：实例身份记录。原子替换写入，损坏文件保留 `.corrupt-*` 备份并报告，不静默覆盖丢失证据。
- `runtime/logs/<服务ID>.log`：经过脱敏的输出与管理操作记录；按大小轮转，最多5个文件，每个约10MB。网页最多读取最近128KB，避免大日志卡住页面。日志脱敏覆盖常见token、密钥字段、Bearer和签名URL，不改写业务原日志。
- 每次业务启动有独立轻量 Python supervisor 持续收集输出。退出管理后台不会关闭业务 stdout 管道，日志可继续写入。下次后台重新验证 PID、创建时间、程序、目录、命令摘要和监听归属才恢复控制。
- HTTP 只监听127.0.0.1，精确核对 Host。API 要求当前会话 token，变更请求再核对 Origin 和 JSON 类型；不开放跨站读取或任意路径读写接口。无监听查询权限时显示实际限制，不凭HTTP成功猜测归属。

## 验证

```powershell
python -m compileall -q lsm launcher.py
node --check static/app.js
python -m unittest discover -s tests -v
```

测试包含真正的隔离 HTTP 进程启动/停止/重启、后台进程退出和重开恢复、来源防护、外部只读与错误身份拒杀。Node 仅用于可选的 JS 语法检查，管理台运行不依赖 Node。

显式真实工具验收：`python tests\real_tools_smoke.py`，先核对外部实例，存在外部任务则停止测试；只清理该次测试创建的实例。结果位于 `test-artifacts/real-tools-result.json`。完整验收与范围见 docs/verification.md。

## 当前限制

扫描采用静态证据，不保证任意下载程序、EXE、Docker/WSL、系统服务或多命令前后端项目可一键接入。后台化并立即脱离进程树的自定义脚本需要提供保持前台的入口或适配器；无法证明归属时拒绝控制。进程存活检查只说明业务进程持续存活，不代替业务功能验收。扫描排除项当前为安全默认项加用户额外排除，不能从界面移除内置默认排除。

本项目仅本机使用，不开放局域网/公网；没有开机自启、自动安装、自动升级、自动运行全部工具或自动重启崩溃服务。
